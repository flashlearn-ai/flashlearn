Three stages. One learning loop.

From scattered information to confident contribution.

01 / SOURCE

Start with your project.

Use the code and documentation already in your repository. Scope a large codebase to the area you want to learn first.

Markdown, JavaScript/TypeScript, and Go.
Wiki connectors are planned.

02 / GENERATE

Make the context useful.

Create questions about project concepts, responsibilities, and decisions, with file and commit citations you can verify.

Choose Copilot, OpenAI, Claude, a custom endpoint, or offline extractive recall.

03 / LEARN

Build a daily habit.

Review multiple-choice questions in your terminal or study in the browser. Spaced repetition brings due cards back into your workflow.

Local review with saved schedules.
Native Teams, GitHub, and Slack delivery is planned.

Your project. Your learning loop.

Cards and review schedules stay in your project's .flashlearn/ directory; browser topic insights stay on that device. Offline generation and review run locally. Choosing an AI provider sends selected code and documentation to that provider.

The public demo uses curated samples only. It never accesses your repository.
