Installation

Requires Node.js 22.14 or newer. Install Git for source commit attribution. The npm prerelease is version @@VERSION@@.

The publishing workflow is ready; these npm commands require the maintainer to publish the first prerelease. You can use a source checkout immediately.

npm install --global flashlearn@next
flashlearn --help
flashlearn --version

From a source checkout:

npm ci
npm run build
npm run cli -- --help

Generate, then learn

flashlearn init /path/to/repo
flashlearn generate /path/to/repo
flashlearn start /path/to/repo

Open http://localhost:4173. Generation creates missing storage automatically, so a separate init is optional. The install includes the browser UI; no build is required for npm users.

The current CLI saves the initialized project for later commands. To inspect another repository without changing your shell location:

flashlearn project set /path/to/repo
flashlearn project status -o json
flashlearn question list -o yaml

Command reference

  • init [directory]: create missing local state and save the project selection.
  • generate [directory]: extract, validate, and persist cards.
  • start [directory] --port 4173: serve the local Teams-style review client and API.
  • project set <directory>: save the project directory.
  • project show: show the effective project.
  • project status: show card and review counts.
  • question list and question get <id>: inspect generated content.

Queries accept -o text|json|yaml. Use project --help or question get --help for contextual help. An explicit directory wins; otherwise FLASHLEARN_PROJECT overrides the saved user selection. Current defaults are localhost and port 4173.

Local-first data boundaries

Cards, canonical spaced-repetition review state, and project settings are stored under .flashlearn/ in the repository. Keep generated content out of Git. Saved project selection lives under $XDG_CONFIG_HOME/flashlearn/config.json or ~/.config/flashlearn/config.json.

The live review client stores topic-insights event history in browser localStorage on the current device. This history is separate from the canonical review state in .flashlearn/review.json, is not synchronized across browsers or devices, and is removed when site data is cleared.

Offline extraction reads local Markdown and Go/JavaScript/TypeScript documentation. To enable AI generation, configure FLASHLEARN_ENDPOINT_URL and FLASHLEARN_ENDPOINT_MODEL. Optional authentication uses FLASHLEARN_ENDPOINT_API_KEY. Never put credential values into repository files.

Configured endpoints receive code. Choose a trusted local or hosted endpoint and account for its permissions and retention. Local repository access controls do not automatically apply to that endpoint.

Daily-workflow integrations

Today you can review through a local Teams-style interface and use the CLI from repository workflows. Native Microsoft Teams, GitHub, and Slack delivery integrations are planned, not currently installed bots or apps. Repository ingestion is available today; wiki connectors are planned.

Help and updates

Report problems in GitHub Issues with CLI/Node versions and reproducible steps. Keep private code, decks, and credentials out of reports. See the release runbook for build and publishing instructions.
